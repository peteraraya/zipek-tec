## 3. Respaldo de información

- [ ] **El respaldo no es viable o no se puede confirmar antes de intervenir.** Motivo informado:  
  __________________________________________________________________________
- [ ] **No se intervendrá todavía.** Primero entregaré o acordaré un respaldo independiente.

Si se solicita un respaldo, autorizo la copia solo de los datos especificados arriba y su uso únicamente para esta orden. Se verificará, cuando sea técnicamente posible, que la copia se haya completado. Una copia no garantiza que todos los archivos estén íntegros, sean legibles o puedan recuperarse; tampoco garantiza la recuperación de datos inaccesibles, dañados o sobrescritos. Cualquier intento de recuperación se cotiza y autoriza por separado si no está incluido en las tareas y el precio anteriores.

No entregues contraseñas por escrito en este documento. Si el servicio requiere iniciar sesión, ingresa tú la clave cuando sea posible o acuerda con el técnico un método temporal y seguro. El técnico no debe conservar contraseñas después del servicio.

## 4. Riesgos y comunicación

El cliente declara haber informado problemas conocidos del equipo y entiende que equipos con fallas previas, discos deteriorados, interrupciones eléctricas o defectos de hardware pueden fallar o perder información durante una intervención, aunque se actúe con cuidado. El técnico informará hallazgos relevantes y solicitará autorización antes de tareas adicionales; una tarea que requiera autorización no se realizará mientras esta no se obtenga.

Esta constancia registra el alcance acordado y los riesgos explicados; no elimina derechos que correspondan al cliente ni reemplaza las condiciones específicas de la orden de servicio.
